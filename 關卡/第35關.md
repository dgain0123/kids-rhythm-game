# 第35關：速度50（第三大關卡「第一行第三小節」的第6關）

> 這是「第35關」的唯一規格正解檔。此關要改規則，先改這裡，程式/資料以本檔為準。

## 位置
- 大關卡（章節）：**第一行第三小節**；是這個章節的**第6關**。
- 標題就是 **「速度50」**（不冠關號；跟拍關卡標題＝速度BPM）。
- 第34關「速度40」過關後按「下一關 →」進來。

## 目標玩法（太鼓達人式）
- **內容跟第34關（速度40）一模一樣、只有速度不同**：第1~4小節各四組十六分音符（64 顆）
  + 第5小節第1拍 1 個四分音符收尾 → **共 65 下、5 小節**。
- **BPM 50**（＝MIDI 的 tempo）→ 十六分音符的間隔＝1/4 拍＝**每 0.3 秒打一下**，
  65 下共 19.2 秒。
- 上面鼓譜（現在該打的音符亮橘、打到變綠）、下面太鼓軌道；開始前只放 1 隻角色、不掛號碼牌。
- 譜面 5 小節，桌機可視窗上限 4 小節 → **桌機也是捲動模式**（同第一大關卡的 5 小節關卡）。

## 判定規則
- 容許誤差：**1/4 拍**（`toleranceBeats: 0.25`；BPM 50 → **±0.3 秒**＝剛好一個
  拍點間隔，跟第9/20~29關「容許＝一個拍點間隔」的寬鬆度一致）。
- 其餘同第9關：打擊依音樂時間歸給最近的未打音符、打錯時間不懲罰、
  65 顆全打到→過關、音樂放完有漏打→失敗。

## 譜面與音樂資料
- 譜：`charts/level35.json`（來源 `midi/第35關.mid`，原始 MIDI 已備份進專案）。
  64 顆 `type: "sixteenth"` + 1 顆 `type: "quarter"`（beat 16.0），`maxHits: 65`。
- MIDI 來源：**`tools/retempo_midi.py` 從 `midi/第34關.mid` 只換 tempo 產生**
  （音符 tick 與第34關逐一相同 → 節拍網格保證一樣，內容真的只差速度）。
- 音樂：`sounds/music/level35.m4a`（**25.7 秒**；1 秒緩衝 + 預備拍 + 音樂 + 終止衰減與靜音緩衝），
  由 `tools/make_level35_music.py` 產生。最後一下在 **21.4 秒**，
  之後只剩 1.35 秒終止衰減、再來**全靜音**到檔尾（音樂到最後一下就結束，2026-08-14 使用者裁示；±0.3 秒容許窗照樣開滿，守門⑥＋收尾測試釘住）。
- **音樂＝第三大關卡的章節風格**（自製**小星星** MIDI ＋ GeneralUser GS 取樣音源
  尼龍吉他，`fluidsynth -R 0 -C 0` 離線 render＝**完全乾聲**；F 大調 4/4，
  2026-08-14 使用者從三個候選試聽選定）。
  素材＝`sounds/music/source/twinkle_guitar_hit1.2s.wav`（4/4 **200BPM**，
  一小節 1.2 秒 × 20 小節），由
  `python3 tools/make_twinkle_render.py --hit 1.2 --bars 20` 產生。
  **一拍＝一個拍點**（音樂速度＝關卡速度×4）→ 同章節內嚴格遞增（守門⑧釘住）。
- **預備拍**：4 拍英文人聲 one/two/three/four，每 0.3 秒一聲＝拍點間隔（速度50以下規矩的最後一關）；**疊得最兇**約 0.42~0.49 秒。速度60起改成一拍一聲就不再疊。
  **純人聲、底下不疊節拍器**；人聲固定用 `sounds/voice/*.wav` 本地檔。
- **節拍器**：每個拍點一聲木魚 1100Hz（各章共用，使用者裁示）。
- **音量**：只調音量、不壓縮（`CLEAN_MASTER`），跟其他關卡同水位（守門⑨釘住）；
  節拍器對齊誤差 0ms（匹配濾波逐拍比對過）。

## 轉檔指令（重出譜時用）
```bash
python3 tools/retempo_midi.py --src midi/第34關.mid --bpm 50 -o midi/第35關.mid
python3 tools/mid2json.py midi/第35關.mid -o charts/level35.json \
  --title "速度50" --hint "更快了！四個一組，最後一下長音～" \
  --tolerance 0.25 --music "./sounds/music/level35.m4a" --lead-in 2.2 --pre-roll 1 \
  --metronome sixteenth
```
音樂重做：`python3 tools/make_level35_music.py`
（素材重做：`python3 tools/make_twinkle_render.py --hit 1.2 --bars 20`）
