# 第14關：速度60（跟拍模式・四倍速）

> 這是「第14關」的唯一規格正解檔。此關要改規則，先改這裡，程式/資料以本檔為準。

## 目標玩法
- 跟第9~11關同樣的太鼓達人式玩法，但 **BPM 60＝第9關的六倍速**：
  小朋友**每 0.5 秒打一下、共 33 下**。
- 譜面（跟 MIDI 一致）：**第1~4小節各 8 個八分音符**（各 4 組符樑）、小節線隔開、
  **第5小節 1 個四分音符**收尾。音符大小固定（同第9關）；**譜面最多顯示 4 小節**，
  這關超過了，遊戲中譜面會跟著進度往左捲動。
- 預備拍固定規矩：**4 拍英文人聲數拍 one/two/three/four**（每 0.5 秒一聲，
  三層鏈：真人錄音>edge-tts Libby>say），前面加 1 秒開頭緩衝。
- 標題不寫「打幾下」（第10關起的規矩）。

## 判定規則
- 容許誤差：**半拍以內**（`toleranceBeats: 0.5`；BPM 60 → **±0.5 秒**）。
- 其餘同第9關：打擊依音樂時間歸給最近未打音符、打錯不懲罰、
  全打到→過關、音樂放完有漏打→失敗。

## 譜面與音樂資料
- 譜：`charts/level14.json`（來源 `midi/第14關.mid`，原始 MIDI 已備份進專案）。
- 音樂：`sounds/music/level14.m4a`（22.5 秒 = 1 秒緩衝 + 2 秒預備拍 + 16 秒伴奏
  (8 個和聲段×2秒 C G Am F | C Am F G，鐘聲每拍點走 根→三→五→三) + 終止 C 和弦收尾），
  由 `tools/make_level14_music.py` 合成。
- **節拍器**：八分音符（每 0.5 秒）一聲木魚，脈動不間斷（規矩見第9關）。
- json 關鍵欄位：`bpm: 60`、`toleranceBeats: 0.5`、`leadInSec: 3`(含開頭1秒緩衝
  `preRollSec: 1`)、`metronome: "eighth"`。

## 轉檔指令（重出譜時用）
```bash
python3 tools/mid2json.py midi/第14關.mid -o charts/level14.json \
  --title "第14關：速度60" --hint "超級快囉！跟著拍子打鼓！" \
  --tolerance 0.5 --music "./sounds/music/level14.m4a" --lead-in 3 --pre-roll 1 --metronome eighth
```
