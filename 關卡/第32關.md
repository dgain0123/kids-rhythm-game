# 第32關：速度20（第三大關卡「第一行第三小節」的第3關）

> 這是「第32關」的唯一規格正解檔。此關要改規則，先改這裡，程式/資料以本檔為準。

## 位置
- 大關卡（章節）：**第一行第三小節**；是這個章節的**第3關**。
- 標題就是 **「速度20」**（不冠關號；跟拍關卡標題＝速度BPM）。
- 第31關「速度10」過關後按「下一關 →」進來。

## 目標玩法（太鼓達人式）
- 譜面：**第1~2小節各四組十六分音符（共 32 顆）**，小節線隔開，**第3小節第1拍＝1 個四分音符收尾** → **共 33 下、3 小節**。
- **BPM 20**（＝MIDI 的 tempo）→ 十六分音符的間隔＝1/4 拍＝**每 0.75 秒打一下**，
  33 下共 24.0 秒。
- 上面鼓譜（現在該打的音符亮橘、打到變綠）、下面太鼓軌道；開始前只放 1 隻角色、不掛號碼牌。
- 譜面 3 小節，桌機可視窗上限 4 小節＝剛好放得下（手機仍捲動）。

## 判定規則
- 容許誤差：**1/4 拍**（`toleranceBeats: 0.25`；BPM 20 → **±0.75 秒**＝剛好一個
  拍點間隔，跟第9/20~29關「容許＝一個拍點間隔」的寬鬆度一致）。
- 其餘同第9關：打擊依音樂時間歸給最近的未打音符、打錯時間不懲罰、
  33 顆全打到→過關、最後一顆容許窗一關、有漏打→立刻失敗(不等檔尾)。

## 譜面與音樂資料
- 譜：`charts/level32.json`（來源 `midi/第32關.mid`，原始 MIDI 已備份進專案）。
  32 顆 `type: "sixteenth"` + 1 顆 `type: "quarter"`（beat 8.0），`maxHits: 33`。
- MIDI：程式照使用者的 `恩典.mid` 音符格子長出（pattern 重複 2 次＋收尾四分音符），tempo 20。
- 音樂：`sounds/music/level32.m4a`（**32.8 秒**；1 秒緩衝 + 預備拍 + 音樂 + 終止衰減與靜音緩衝），
  由 `tools/make_level32_music.py` 產生。最後一下在 **28.0 秒**，
  之後 0.35 秒終止音**直接停**、再來全靜音到檔尾（音樂到最後一下就結束，2026-08-14 使用者裁示；±0.75 秒容許窗照樣開滿，守門⑥＋收尾測試釘住）。
- **音樂＝第三大關卡的章節風格**（自製**小星星** MIDI ＋ GeneralUser GS 取樣音源
  尼龍吉他，`fluidsynth -R 0 -C 0` 離線 render＝**完全乾聲**；F 大調 4/4，
  2026-08-14 使用者從三個候選試聽選定）。
  素材＝`sounds/music/source/twinkle_guitar_hit3s.wav`（4/4 **80BPM**，
  一小節 3 秒 × 10 小節），由
  `python3 tools/make_twinkle_render.py --hit 3 --bars 10` 產生。
  **一拍＝一個拍點**（音樂速度＝關卡速度×4）→ 同章節內嚴格遞增（守門⑧釘住）。
- **預備拍**：4 拍英文人聲 one/two/three/four，每 0.75 秒一聲＝拍點間隔；字長 0.72~0.79 秒 → 最長的字略疊約 0.04 秒（規矩照舊）。
  **純人聲、底下不疊節拍器**；人聲固定用 `sounds/voice/*.wav` 本地檔。
- **節拍器**：每個拍點一聲木魚 1100Hz（各章共用，使用者裁示）。
- **音量**：只調音量、不壓縮（`CLEAN_MASTER`），跟其他關卡同水位（守門⑨釘住）；
  節拍器對齊誤差 0ms（匹配濾波逐拍比對過）。

## 轉檔指令（重出譜時用）
```bash
python3 tools/mid2json.py midi/第32關.mid -o charts/level32.json \
  --title "速度20" --hint "變長囉！四個一組，最後一下長音～" \
  --tolerance 0.25 --music "./sounds/music/level32.m4a" --lead-in 4 --pre-roll 1 \
  --metronome sixteenth
```
音樂重做：`python3 tools/make_level32_music.py`
（素材重做：`python3 tools/make_twinkle_render.py --hit 3 --bars 10`）
