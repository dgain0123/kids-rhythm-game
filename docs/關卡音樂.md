# 關卡音樂：每個大關卡的音樂全都不一樣

> 這是「章節音樂風格」這條規則的**唯一正解檔**。要改規則先改這裡，
> 程式（`tools/music_style.py`）與測試（`tests/test_music_style.py`）以本檔為準。

## ★ 規矩（2026-08-02 使用者定案）

**每一個大關卡（章節）的背景音樂都要跟其他大關卡明顯不同**——
**調性、樂器音色、節拍器音色、和聲進行** 四項全部都要換，
讓小朋友一聽就知道「換章節了」。同一個大關卡底下的小關卡則共用同一套風格
（只有速度/長度不同），聽起來是同一個世界。

## 不變的部分（跟章節無關，所有跟拍關卡都一樣）

1. **軟起音樂器**：避免喇叭聲被麥克風的打鼓偵測誤判成鼓聲（見 [打鼓偵測](打鼓偵測.md)）。
2. **拍點音最亮**：小朋友要打的那一下，一定是當下最明顯的聲音。
3. **節拍器每個拍點一聲**（音色隨章節換），預備拍底下也墊著 → 脈動不間斷。
4. **預備拍**：4 拍英文人聲 one/two/three/four（`tools/voice_count.py`，
   間隔規矩見 [關卡系統](關卡系統.md)）。
5. 音樂**烤成單一 m4a**（含節拍器與人聲），遊戲只播一個檔（見 [關卡系統](關卡系統.md)）。

## 實際步驟 ①：新增一個大關卡

1. **選風格**：跑試聽腳本產生 2~3 個候選各約 15 秒，`afplay` 放給使用者聽、讓他挑
   （候選就用正式的 `music_style` 產生，聽到的＝之後會出貨的聲音）。
2. **登記**：在 `tools/music_style.py`
   - 新增一個 `Style` 子類別，實作 `hit / chord / bass / fill / click`（可抄現有的改音色），
     並填 `name / key / instruments / metronome / prog`。
   - 在 `STYLES` 加一筆 `章節編號: 新風格()`，**四項都要跟其他章節不同**。
3. **在 `js/main.js` 的 `GROUPS` 加這個大關卡**（章節編號＝在 GROUPS 裡的順序，1 起算）。
4. **跑守門**：`python3 tests/guard_test.py` → 綠才算數。
   （順序反過來也行：先加 GROUPS 會直接紅，測試訊息會告訴你去 `STYLES` 補。）
5. 章節名、關卡表更新到 [關卡系統](關卡系統.md)，本檔的登記表也補一行。

## 實際步驟 ②：在某個大關卡底下新增一關（跟拍關卡）

1. 寫 `tools/make_levelN_music.py`，開頭固定這樣拿風格（**不要自己內建音色**）：
   ```python
   from music_style import Mixer, style_for_chapter
   CHAPTER = 2                        # 這關屬第幾個大關卡
   STYLE = style_for_chapter(CHAPTER)
   mx = Mixer(總長秒數)
   STYLE.chord(mx, t0, 長度, seg); STYLE.bass(mx, t0, seg["bass"])
   STYLE.hit(mx, t, 音名, accent=True); STYLE.click(mx, t); STYLE.fill(mx, t, 音名)
   mx.finish("…/sounds/music/levelN.m4a")
   ```
2. 產音樂 → 轉譜（`tools/mid2json.py`，`--music/--lead-in/--pre-roll/--metronome`）。
3. **驗音樂與譜面對齊**（一定要做，見下）。
4. 加進 `js/main.js` 該章節的 `levels`、`sw.js` 的預抓清單（chart + m4a）、寫 `關卡/第N關.md`。
5. `python3 tests/guard_test.py` 全綠。

## 對齊驗證（每次做完音樂都要跑）

解碼 m4a 找起音點，跟 chart 算出來的拍點比對，**誤差要 ~0.000 秒**：

```bash
afconvert -f WAVE -d I16@44100 -c 1 --mix sounds/music/levelN.m4a /tmp/x.wav
# 讀 /tmp/x.wav 找能量尖峰 → 對照 charts/levelN.json 的 beat*60/bpm + leadInSec
```
（第20關實測：預備拍在 1/3/5/7 秒、12 個拍點在 9~31 秒、誤差 0.000 秒。）

## 守門機制（規則不會被忘記）

- `tests/test_music_style.py` 釘住：
  ① `js/main.js` 的每個大關卡都要有 `STYLES` 條目（漏加就紅、訊息直接告訴你怎麼補）
  ② 任兩章的 **調性／樂器／節拍器／和聲進行** 都不可以一樣
  ③ 沒定義風格的章節呼叫 `style_for_chapter` 一定要爆（不可默默沿用別章音樂）
  ④ 每個跟拍關卡 json 指到的音樂檔真的存在
  ⑤ `make_level20_music.py` 確實走章節風格（`CHAPTER=2`）
- 改任何 `.py` 會由全域 PostToolUse hook 自動跑 `tests/guard_test.py`，紅就擋下編輯。
- **實測過**：臨時在 `GROUPS` 加第 3 大關卡而不補風格 → 守門立刻紅並指名要去 `STYLES` 補。
