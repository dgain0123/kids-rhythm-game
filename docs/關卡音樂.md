# 關卡音樂：每個大關卡的音樂全都不一樣

> 這是「章節音樂風格」這條規則的**唯一正解檔**。要改規則先改這裡，
> 程式（`tools/music_style.py`、`tools/track_music.py`）與測試
> （`tests/test_music_style.py`）以本檔為準。

## ★ 規矩（2026-08-02 使用者定案）

**每一個大關卡（章節）的背景音樂都要跟其他大關卡明顯不同**——
**調性、樂器音色、節拍器音色、和聲進行** 全部都要換，
讓小朋友一聽就知道「換章節了」。同一個大關卡底下的小關卡則共用同一套風格
（只有速度/長度不同），聽起來是同一個世界。

**光換音色不夠（2026-08-03 使用者打槍過一輪）**：同一套骨架（正弦疊加音色＋長 pad＋
貝斯＋同樣編曲）只改音色參數，聽起來還是同一個世界。要換就連
**合成方式／編曲結構／空間感／音階語言**一起換 —— 或者乾脆換條路線用現成曲目。

## 兩條路線

| | ① 程式合成 | ② 現成曲目 |
|---|---|---|
| 實作 | `tools/music_style.py`（`Style` 子類別，`kind="synth"`） | `tools/track_music.py`＋`kind="track"` 的風格 |
| 適合 | 要完全掌控每個音、極慢速關卡 | 要「真樂器/真編曲」的氛圍，最省事 |
| 素材 | 無 | **只收 CC0／公共領域**，放 `sounds/music/source/`，登記在 [來源與授權](../sounds/music/source/來源與授權.md) |
| 變速 | 直接照關卡拍點合成 | 自動變速對齊（見下） |

## 不變的部分（跟章節、路線都無關）

1. **軟起音樂器／音量壓低**：避免喇叭聲被麥克風的打鼓偵測誤判成鼓聲（見 [打鼓偵測](打鼓偵測.md)）。
2. **拍點音最亮**：小朋友要打的那一下，一定是當下最明顯的聲音（現成曲目就靠節拍器擔任）。
3. **節拍器每個拍點一聲**（音色隨章節換），預備拍底下也墊著 → 脈動不間斷。
4. **預備拍**：4 拍英文人聲 one/two/three/four（`tools/voice_count.py`，間隔規矩見 [關卡系統](關卡系統.md)）。
5. 音樂**烤成單一 m4a**（含節拍器與人聲），遊戲只播一個檔。

|---|---|---|---|---|---|---|
| 1 | 第一行第一小節（level9~18） | 合成 | 鐘琴音樂盒＋暖 pad | C 大調（C G Am F） | 鐘琴＋雙振盪暖 pad＋正弦貝斯 | 木魚 1100Hz |
| 2 | 第一行第二小節（level20~） | **現成 CC0 曲目** | 旋轉木馬風琴 | 原曲調性（只變速不變調） | 遊樂園旋轉木馬管風琴實錄 | 高音木塊 1500Hz |

備用的合成風格（`CANDIDATES`，開新章節可直接用或當範本）：音樂盒(F大調/三角鐵)、

拿來當新章節前先確認跟既有章節聽起來真的不一樣。

## 現成曲目的變速對齊（`tools/track_music.py`）

一首現成曲子要當關卡音樂，**它的拍子必須落在關卡的拍點上**。管線：

1. **量週期**：起音包絡自相關抓粗值 → 梳狀能量在 ±7% 內精修。
   ⚠️ **不要用 `librosa.beat.beat_track`**：管風琴這種連續音色它會抓錯
   （實測把 97.2BPM 抓成 95.5，還會跳節拍層級）。
2. **選 N 與變速倍率**：「一個遊戲拍點 = N 拍」，讓倍率越接近 1 越好；
   N∈{3,4,6,8}（容易落在小節線上）優先、容許範圍放寬到 0.70~1.45。
3. **time-stretch**（保持音高，librosa 相位聲碼器）。
4. **驗證**（自動，過不了就 raise）：
   - 對比度 ≥1.20（音樂的拍子真的落在目標網格上；實測好素材是 9~13）
   - 前後段相位差（整段累積漂移）≤80ms
5. 從量到的拍子相位切入 → 鋪到需要長度（不夠就接續循環）→
   疊 4 拍人聲預備拍（騎在音樂上，像真的樂團 count-in）＋每個拍點一聲節拍器 → 淡出 → m4a。

**同一首曲子可以給同章節不同速度的關卡用**：只要換 `hit_sec`（該關拍點間隔），
管線會重新選 N 與倍率。第20關實例：97.23BPM → 一個拍點=3拍、放慢 7.4% → 90BPM，
對齊對比度 9.2、整段漂移 22ms。

## 實際步驟 ①：新增一個大關卡

1. **選風格**：做 2~4 個候選各約 15 秒（用正式管線做，聽到的＝之後會出貨的聲音），
   `afplay` 放給使用者聽、讓他挑。走現成曲目就先在
   [Openverse API](https://api.openverse.org/v1/audio/?q=…&license=cc0) 撈 CC0 素材。
2. **登記**：`tools/music_style.py`
   - 合成路線：新增 `Style` 子類別（實作 `hit/chord/bass/fill/click`、填
     `name/key/instruments/metronome/prog`）。
   - 現成曲目：新增 `kind="track"` 的類別，填 `source/license/credit/source_url` 與 `click`，
     素材放 `sounds/music/source/`，並在 [來源與授權](../sounds/music/source/來源與授權.md) 加一列。
   - 在 `STYLES` 加一筆 `章節編號: 新風格()`，**要跟其他章節明顯不同**。
3. **在 `js/main.js` 的 `GROUPS` 加這個大關卡**（章節編號＝在 GROUPS 裡的順序，1 起算）。
4. **跑守門**：`python3 tests/guard_test.py` → 綠才算數。
5. 章節名與關卡表更新到 [關卡系統](關卡系統.md)，本檔登記表也補一行。

## 實際步驟 ②：在某個大關卡底下新增一關（跟拍關卡）

1. 寫 `tools/make_levelN_music.py`，**不要自己內建音色**，照章節拿風格：
   ```python
   from music_style import style_for_chapter
   from track_music import render          # 現成曲目路線
   CHAPTER = 2
   STYLE = style_for_chapter(CHAPTER)
   render(STYLE, hit_sec=該關拍點間隔, n_hits=要打幾下,
          out_path=".../sounds/music/levelN.m4a", lead_hits=4, pre=1.0)
   ```
   （合成路線改用 `music_style.Mixer` ＋ `STYLE.chord/bass/hit/click`。）
2. 產音樂 → 轉譜（`tools/mid2json.py`，`--music/--lead-in/--pre-roll/--metronome`）。
3. **驗音樂與譜面對齊**（一定要做，見下）。
4. 加進 `js/main.js` 該章節的 `levels`、`sw.js` 的預抓清單（chart + m4a）、寫 `關卡/第N關.md`。
5. `python3 tests/guard_test.py` 全綠。

## 對齊驗證（每次做完音樂都要跑）

- 現成曲目路線：`track_music.render` 內建對比度與漂移檢查，過不了直接 raise。
- 合成路線／最終成品：解碼 m4a 找起音點，跟 chart 算出來的拍點比對，誤差要 ~0.000 秒：
  ```bash
  afconvert -f WAVE -d I16@44100 -c 1 --mix sounds/music/levelN.m4a /tmp/x.wav
  # 讀 /tmp/x.wav 找能量尖峰 → 對照 charts/levelN.json 的 beat*60/bpm + leadInSec
  ```

## 守門機制（規則不會被忘記）

`tests/test_music_style.py` 釘住：
① `js/main.js` 的每個大關卡都要有 `STYLES` 條目（漏加就紅，訊息直接告訴你怎麼補）
② 任兩章的 **調性／樂器／節拍器／和聲進行** 都不可以一樣
③ 沒定義風格的章節呼叫 `style_for_chapter` 一定要爆（不可默默沿用別章音樂）
④ **現成曲目章節**：素材檔要在、授權必須 CC0/公共領域、來源要登記在 來源與授權.md
⑤ 每個跟拍關卡 json 指到的音樂檔真的存在
⑥ `make_level20_music.py` 確實走章節風格（`CHAPTER=2`）

改任何 `.py` 會由全域 PostToolUse hook 自動跑 `tests/guard_test.py`，紅就擋下編輯。
**實測過**：臨時在 `GROUPS` 加第 3 大關卡而不補風格 → 守門立刻紅並指名要去 `STYLES` 補；
把第2章換成現成曲目時，守門也馬上抓到「沒有和聲進行」「缺 來源與授權.md」。
