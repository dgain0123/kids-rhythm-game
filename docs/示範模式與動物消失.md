## 一、打幾下關卡：每打一下消失一隻動物（2026-11-01 使用者要求）

適用所有「打幾下」(數下數)關卡：第1～8關、打12下（第19關）、打16下（第30關）。跟拍關卡不受影響。

| 代號 | 規則 |
|---|---|
| `[R:count-initial]` | 開始前動物數＝要打幾下，號碼牌 1..N 依序，都看得到 |
| `[R:count-gone-per-hit]` | 打了 k 下 → **正好第 1～k 號**消失（從 1 號開始依序、一下一隻），任何一步都成立 |
| `[R:count-keep-positions]` | 消失＝`visibility` 藏起來、**位置留著**，剩下的動物排版座標全程不變（不跳位） |
| `[R:count-pass]` | 打滿後 1.5 秒沒多打 → 過關（換拉炮），過程不會失敗 |
| `[R:count-fail-restore]` | 打太多下 → 失敗，動物**全部回來**（數量、號碼、位置照原樣）；再玩一次也全部回來 |

實作：`js/characters.js` 的 `hideCharacters(n)`（給第 1～n 號加 `.gone`）；`js/main.js` onState
的 progress/hitOnce 呼叫、fail 呼叫 `showCharacter()`；動畫 `css/style.css` 的 `.char-item.gone`
（先放大 1.2 倍再縮到 0，0.35 秒）。

## 二、示範模式（網址加 `?demo=…`）

| 參數 | 意思 |
|---|---|
| `demo=1` | 正常示範：不開麥克風、自動打 |
| `demo=miss` | 跟拍關故意**漏打最後一顆**（驗失敗路線） |
| `demo=over` | 打幾下關故意**多打一下**（驗失敗路線） |

| 代號 | 規則 |
|---|---|
| `[R:demo-no-error]` | 跑的過程頁面不能有任何 JS 錯誤 |
| `[R:demo-hide-controls]` | 藏靈敏度條、音量條、小按鈕列（選關/重連/試聽）、再玩/下一關按鈕；**音樂出處那行要留**（CC BY 授權要求）；過關/失敗不捲動頁面 |
| `[R:demo-timed-hit-on-time]` | 跟拍關：每顆音符正好在「音樂時間第一次到達拍點」的那一步被打中，不早不晚、每顆只打一次（打的時間＝拍點本身） |
| `[R:demo-timed-all-pass]` | 跟拍關 demo=1：全部打中，**在最後一顆拍點那一步過關**，過程不會失敗 |
| `[R:demo-timed-miss-fail]` | 跟拍關 demo=miss：最後一顆容許窗一關（`endT`＝最後一顆＋max(容許誤差, 0.5 秒)）那一步**立刻失敗**，不等檔尾、不會過關 |
| `[R:count-demo-1hz]` | 打幾下關的示範：按開始後**每 1 秒自動打一下**（第 k 下在第 k 秒） |

示範模式下 `window.__demo` 開放唯讀的 `game`／`chart`／`ready`（關卡＋音樂載好），只給檢查器用。

## 三、示範影片（mp4）

```bash
python3 tools/record_demo.py 18     # → videos/第18關_示範.mp4（1920×1080、30fps）
```

| 代號 | 規則 |
|---|---|
| `[R:video-sync]` | 解析度＝寬×高×scale；**聲音跟畫面一樣長**（差 ≤0.05 秒）；跟拍關的過關時刻＝預備拍(leadInSec)＋最後一顆拍點（差 ≤1 格）。`record_demo.py` 錄完自動檢查，不過就報錯 |

做法（實際步驟）：
1. 本機伺服器＋無頭 Chromium 開 `index.html?level=N&demo=1`，等 `__demo.ready` 與圖片載完才按開始。
2. **虛擬時鐘**（`tools/demo_rules.py` 的 `INIT_JS`，唯一一份）：`AudioContext.currentTime`、
   `performance.now`、`requestAnimationFrame` 全換掉，每格推 2×1/60 秒、截一張 → 30fps，不管截圖多慢都準。
3. 聲音不是從瀏覽器錄：ffmpeg 把關卡音樂（第 0 秒＝遊戲音樂起播）＋在過關那一刻疊 `sounds/cheer.mp3`。
4. 影片檔不進 git（`videos/` 已忽略；公開 repo 不放大檔）。

## 五、踩過的坑（這次）

- **無頭瀏覽器（Chromium/WebKit）解不了 m4a(AAC)**：錄影/檢查時把 `*.m4a` 請求換成 wav（檢查只要遊戲拿到音訊，用 0.5 秒靜音 wav）。
- **瀏覽器裡真的在播音樂**：截圖比實際時間慢，真實音樂先放完 → `onended` 觸發「音樂放完＝結算」→ 判失敗。
  虛擬時鐘要把 `AudioBufferSourceNode.prototype.start` 換成空函式。
- **ffmpeg `apad` 不給長度會無限跑**：用 `apad=pad_dur=10,atrim=0:總長`。
- **換掉 rAF 後，Playwright `wait_for_function` 預設靠 rAF 輪詢 → 永遠等不到**：一律加 `polling=50` 之類的毫秒數。
- **開始按鈕比關卡載入早出現**：要等 `__demo.ready`，不要用固定等待秒數。
- **按開始會重畫角色（新的 `<img>`）**：在同一段 JS 裡連推很多步，中間沒給圖片載入，量到的是圖片還沒載好的排版
  → 按開始後先等 `document.images` 全部 `complete` 再紀錄（實際遊戲只閃幾毫秒，不是 bug）。
