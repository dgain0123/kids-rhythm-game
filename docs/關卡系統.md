# 關卡系統

關卡是**資料驅動**的：一個 `charts/levelN.json` = 一關，目錄與畫面自動生成。

## 關卡清單(兩層：大關卡→小關卡，2026-07-28 改制)
`js/main.js` 的 `GROUPS` 決定結構：每個大關卡(章節)有 title 和 levels 清單。
加小關卡＝該章節 levels 加一項；加章節＝GROUPS 加一組。目錄先選大關卡再選小關卡
(遊戲中☰直接回目前章節)；「下一關」只在同章節內接續。
| 大關卡 | 收哪些關 | 標題規矩 |
|---|---|---|
| 1 第一行第一小節 | level1~18 | 標題含關號(如「第8關：打8下」「第13關：速度50」) |
| 2 第一行第二小節 | level19~20 | 標題**不冠關號**(如「打12下」「速度10」)，卡片自己會標章節內第幾關 |
`?level=N` 用的是**跨章節的全域關號**(第19關＝`?level=19`)，檔案也照全域編號
(`charts/level19.json`、`關卡/第19關.md`)。

## 譜格式 charts/levelN.json
```json
{
  "title": "第2關：打2下",
  "maxHits": 2,
  "hint": "看到兩個音符，打2下鼓！",
  "notes": [
    { "type": "quarter", "drum": "snare" },
    { "type": "quarter", "drum": "snare" }
  ]
}
```
- `maxHits`：要打幾下（＝角色數＝過關所需）。
- `notes[].type`：`quarter`(四分) / `eighth`(八分) / `triplet`(一拍三連音的一顆＝1/3 拍，
  三顆一組)。時值表：`tools/mid2json.py` 的 `NOTE_VALUES` 與 `js/render.js` 的 `DUR`
  **兩邊要一致**。`drum`：鼓件。
- **沒有 `bpm`、音符沒有 `beat` ＝數下數關卡**(不判拍子)；有才是跟拍關卡。
  轉檔要出數下數關卡用 `--count-mode`(由 `tests/test_mid2json.py` 釘住)。

## 跟拍模式（第9關起）
chart 有 `bpm` 且音符有 `beat` 就自動走跟拍模式，新增欄位：
- `bpm`：速度。`notes[].beat`：每個音符在第幾拍（轉檔器自動算）。
- `toleranceBeats`：容許誤差（拍），**每關可以不一樣**（第9關 0.5＝半拍）。
- `music`：背景音樂路徑。`leadInSec`：音樂開頭預備拍長度（秒）。
- `metronome`：節拍器細分（如 `eighth`），**每關可以不一樣**；規矩＝每個跟拍關卡的
  音樂都要含節拍器聲（烤在音樂檔裡，此欄位是規格記錄）。
- **預備拍固定規矩（2026-07-28 定案）：每關開頭固定 4 拍英文人聲數拍 one/two/three/four**
  （間隔：**速度50以下＝該關的拍點間隔**(八分關卡=八分、三連音關卡=三連音，如第20關每2秒一聲)；
  **速度60起＝四分音符(一拍)一聲**，八分太趕；聲源三層鏈：真人錄音>edge-tts Libby>say，見 `tools/voice_count.py`；
  人聲**不修剪頭尾**、用起音點對齊拍點；音檔最前面加 1 秒緩衝 `preRollSec` 躲播放暫態），
  之後每個新關卡的音樂產生器都照辦。
- 跟拍關卡開始前只顯示 1 隻角色、不掛號碼牌（角色會在太鼓軌道上跑）。
- **跟拍關卡標題＝速度BPM**：第一大關卡寫「第N關：速度BPM」(如「第13關：速度50」)；
  第二大關卡起不冠關號、只寫「速度BPM」(如第20關「速度10」)。都不寫打幾下。
- **該關速度＝來源 MIDI 的 tempo**(第18關.mid=100、第20關.mid=10)，轉檔器直接讀進 `bpm`。
- 譜面音符**大小固定**（同第9關）；放不下時畫布自動加寬、舞台/頁面跟著變寬（`.stage.wide`）。
- **譜面可視窗依螢幕寬自動決定（桌機最多 4 小節、手機 1~2 小節，2026-07-28 定案）**：
  超出可視窗的譜，捲動方式跟太鼓軌道同邏輯——
  左邊有一條**固定基準粗線**(貫穿整個五線譜，任何音高都碰得到)，目前該打的音符
  釘在線上、整片譜**一路往左滑到最後一下**（`state.curBeat` 驅動，`needsScroll` 判斷）。
判定：打的那下依音樂時間歸給「最近的還沒打到的音符」，誤差內→變綠；
全綠→過關；音樂放完有沒打到的→失敗；打錯時間不懲罰。
預備拍＝**英文人聲數拍 one~four**(三層鏈:真人錄音>edge-tts>say，烤在音樂檔裡)＋畫面倒數大字，之後「現在該打」的音符亮橘。
規格詳見 `關卡/第9關.md`。

## 譜面繪製（js/render.js `drawNotes`）
- 畫五線譜 + 音符（黑色實心符頭 + 符桿）。小鼓＝五線譜第三間。
- **依「拍」定位**：四分=1拍、八分=半拍，每拍等寬（兩個八分＝一拍＝一組）。
- 八分音符：**每兩個一組(一拍)打符樑**（`drawBeam`），組跟組分開；落單的畫旗子（`drawFlag`）；**不跨小節連樑**。
- 三連音：**每三個一組(一拍)打符樑**，符樑正上方標斜體「3」（`drawTupletNum`）；
  有三連音的譜五線譜整體**下移 14px**，把「3」的空間讓出來（不然會被畫布上緣切掉）。
- **相鄰音符至少隔 32px**（`MIN_NOTE_PX`）：音符很密的譜(三連音=1/3拍)每拍自動畫寬一點，
  符頭才不會疊在一起；八分(0.5拍)以上算出來剛好＝原本的 64px/拍，**舊關卡版面完全不變**。
- 超過一小節(4/4)自動畫**小節線**並把兩小節隔開（跨小節處多留空隙）。
- 最後一顆音符的時值：轉檔器用 MIDI 音符實際長度判(在 Logic 畫多長就是什麼時值)。

## 判定（js/game.js）
狀態機：`ready → progress → hitOnce → pass/fail`。
```
每打一下 hits++：
  hits > maxHits           → fail（打太多）
  hits < maxHits           → progress（還沒打夠，繼續等，不失敗）
  hits == maxHits          → hitOnce，開 1.5 秒視窗；沒再多打 → pass
```
- **不判拍子**：八分/四分只是譜面外觀，實際每個音符＝打一下。
- 「打夠才過關、超過才失敗、不夠繼續等」對幼兒友善（零挫折）。

## 目錄與導覽（js/main.js）
- 一進來顯示**大關卡目錄**→點進去是小關卡卡片（`prefetchTitles` 先抓好各關標題）。
- 點卡片 → `selectLevel` → `goToLevel` 載譜、畫面、角色數 → 顯示「開始遊戲」。
- 遊戲中「☰ 選關」回目錄；過關後「下一關 →」進下一關；`?level=N` 直接進某關。

## 不劇透的設計（使用者要求）
- 打鼓過程**不顯示**「還剩幾下」等文字（progress/hitOnce 狀態列留空）。
- 打到剛好那下角色**不放大不歪斜**（拿掉了會露餡的提示）。
- 不閃黃回饋（拿掉了）。小朋友純看音符/角色數量自己數。

## 每關的規格正解檔
`關卡/第N關.md` 是各關規則的唯一正解檔；改某關先改它，程式/資料以它為準。每個 md 維持 200 行內。
